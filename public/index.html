How it works

    Upload & encrypt

    Your file streams through AES-256-GCM on the server. The storage provider only ever receives ciphertext.

    Share a link or a key

    Send a self-destructing link, a campus key or a class listing. Opening a page never uses up a download.

    It disappears

    When time or downloads run out, the file and its key are deleted. Late visitors see the "self-destructed" page.
